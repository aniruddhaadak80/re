# MCP tools reference

The RevLens MCP server (`npx -y @revlens/mcp` or `revlens mcp`) offers **87 tools**, 2 prompts and 2 resources. The CLI has 54 commands. This page is generated by `node scripts/gen-tool-docs.mjs` from the same TOOLS arrays the server registers, so it always matches the code.

A `?` after a parameter means it is optional. "Reads only" tools never change anything on disk. Hosts see the same information as MCP tool annotations and can ask you before running anything else.

Bridge tools need the external program installed. When it is missing they return `available: false` with install commands instead of failing. See [Bridges, doctor and setup](bridges.md).

## Prompts

- `triage_file`: Walk through a first look at an unknown file: format, risk, behavior, then the right deep tools, with evidence for every claim.
- `explain_function`: Disassemble one function, read its pseudo code and callers, and explain what it does with addresses as evidence.

## Resources

- `revlens://analyzers`: Every analyzer across core and the packages, with what it reads.
- `revlens://tools`: Tool names grouped by area, with whether each one only reads.
