# File formats and output formats

Generated by `node scripts/parity/generate.mjs` from `docs/parity/data/rea-inventory.json` (morluto/rea 6.8.0, commit 55b6d2ca20) and `docs/parity/data/revlens-inventory.json` (RevLens main 2300d9e0d6). Decisions live in `scripts/parity/mapping.mjs`; edit them there and regenerate.

rea is used for scope only. RevLens is not REA and is not affiliated with it.

Input formats: rea's ARTIFACT_FORMAT_IDS (45) plus the formats its dedicated inspect tools read (27). RevLens core detects 33 format ids (elf, pe, macho, macho-fat, wasm, zip, jar, apk, crx, xpi, vsix, npm-tgz, gzip, tar, asar, js, sourcemap, json, pdf, pyc, dex, class, text, unknown, dotnet, ipa, pcap, pcapng, sqlite, har, lua, beam, il2cpp-metadata); package tools read more.

**Totals, input formats.** 72 rows: 47 equal, 2 better, 7 partial, 16 missing (9 of the partial or missing rows are in progress on a round-3 branch). Covered (equal or better): 49 of 72.

**Totals, output formats.** 7 rows: 2 equal, 0 better, 0 partial, 5 missing (0 of the partial or missing rows are in progress on a round-3 branch). Covered (equal or better): 2 of 7.

Status: equal means a RevLens tool does the same job; better means the same job and more; partial means part of the job, with the gap in the note; missing means no RevLens tool does it. "in progress" names the round-3 branch adding it.
