# Test fixtures for @revlens/managed

Every fixture is a real artifact made by the real toolchain, or downloaded from an official source.
The `*.ref.json` / `*.json` files next to them are reference outputs from independent tools, made at
fixture generation time with the scripts in `packages/managed/scripts/`.

## dotnet/

| File | Source | License |
| --- | --- | --- |
| `System.IO.Compression.Brotli.dll` | `runtimes/linux-x64/lib/net8.0/` inside `microsoft.netcore.app.runtime.linux-x64` 8.0.11 from https://api.nuget.org/v3-flatcontainer/microsoft.netcore.app.runtime.linux-x64/8.0.11/microsoft.netcore.app.runtime.linux-x64.8.0.11.nupkg | MIT (.NET runtime) |
| `brotli.ref.json` | `scripts/ref-dotnet.py` using dnfile 0.18.0 (MIT) for metadata and dncil 1.0.2 (Apache-2.0) for IL | generated |
| `newtonsoft.ref.json` | same script with `--summary`, run on Newtonsoft.Json 13.0.3 `lib/netstandard2.0/Newtonsoft.Json.dll` | generated |

Newtonsoft.Json itself (MIT, 705 KB) is not committed. `node packages/managed/scripts/fetch-fixtures.mjs`
downloads it from https://api.nuget.org/v3-flatcontainer/newtonsoft.json/13.0.3/newtonsoft.json.13.0.3.nupkg
into `samples/.cache/managed/`.

## python/

`sample_mod.py` (written for this project, MIT) compiled by CPython 3.8.20, 3.9.25, 3.10.22, 3.11.18
(python-build-standalone via uv), 3.12.15 and 3.13.5 with `scripts/ref-pyc.py`. Each `sample_mod.<v>.json`
is `dis.get_instructions` output of that same interpreter for every code object.

## pyinstaller/

| File | Source |
| --- | --- |
| `mini-carchive.bin` | written by PyInstaller 6.22.3 `CArchiveWriter` and `ZlibArchiveWriter` (`scripts/gen-pyinstaller-fixture.py`), behind a 64 byte stub instead of a bootloader. Nothing in it is runnable. |
| `mini-carchive.ref.json` | PyInstaller's own `CArchiveReader` / `ZlibArchiveReader` view of that file |
| `hello_revlens.py`, `helper_mod.py` | sources for the full onefile build made by `fetch-fixtures.mjs` when `python3 -m PyInstaller` is available (output goes to `samples/.cache/managed/hello_revlens` with a reader reference next to it) |

PyInstaller is GPL-2.0 with a bootloader exception; it is only used to produce fixtures and is not a dependency.

## lua/

`sample.lua` (MIT, this project) dumped with `string.dump` by the Lua 5.1, 5.2, 5.3, 5.4 and LuaJIT 2.1
runtimes bundled in lupa 2.8 (MIT) via `scripts/gen-lua-fixtures.py`. 5.3, 5.4 and LuaJIT also have stripped
dumps. `luajit.ref.json` holds every prototype and raw bytecode word as reported by LuaJIT's built in `jit.util`.

| `beam.ref.json` | pybeam 0.8.1 (MIT) via `scripts/ref-beam.py` | generated |

## evm/

`RevToken` (an OpenZeppelin `ERC20`) and `RevProxy` (an OpenZeppelin `ERC1967Proxy`), OpenZeppelin Contracts
5.1.0 (MIT), compiled with solc-js 0.8.26 (optimizer on, 200 runs) by `scripts/gen-evm-fixtures.mjs`.
`*.runtime.hex` is `evm.deployedBytecode.object`; `evm.ref.json` keeps solc's `methodIdentifiers`,
`deployedBytecode.opcodes` and compiler version for comparison. solc (GPL-3.0) is only used at fixture time.

`src/evm/known.ts` (selector, event and proxy slot table) is generated by `scripts/gen-evm-selectors.mjs`
with keccak256 from js-sha3 (MIT) at generation time.

## native/

`<rid>/*.gz`: gzip of `runtimes/<rid>/native/` System.IO.Compression.Native for linux-x64 (.so), win-x64 (.dll)
and osx-arm64 (.dylib) from the official microsoft.netcore.app.runtime.<rid> 8.0.11 packages on nuget.org,
pulled by `scripts/fetch-native.mjs` with HTTP range requests. MIT (.NET runtime). `exports.ref.json` is
written by `scripts/ref-native-exports.py` from llvm-nm, llvm-readobj and llvm-objdump 19.
